# 이모티콘 캔버스 템플릿 생성기

이모티콘을 그리기 전에 쓸 빈 캔버스 가이드 템플릿을 원하는 설정으로 만들어 **원본 크기 PNG**로 저장하는 웹페이지입니다.
저장한 PNG를 그림 앱(프로크리에이트, 클립 스튜디오 등)에 불러와 그 위에 그리면 됩니다.

서버 없이 HTML·CSS·JavaScript만으로 동작하며, 그리기와 PNG 저장 모두 브라우저 안에서 처리됩니다.

## 기능

| 항목 | 설명 |
| --- | --- |
| 박스 크기 | 가로·세로 px 입력, 360×360 / 1080×1080 빠른 선택, 가로·세로 바꾸기 |
| 박스 개수 | 가로 개수 × 세로 개수 격자 배치 (각 최대 500) |
| 간격 | 가로 간격, 세로 간격, 캔버스 바깥 여백 |
| 테두리 | 켜기/끄기, 두께, 색, 위치(안쪽·가운데·바깥쪽) |
| 배경색 | 흰색, 투명, 인디고(`#3F51B5`), 직접 지정 |
| 톰보(재단선) | 켜기/끄기, 길이, 모서리에서 띄우기, 두께, 색 — 박스 안은 침범하지 않음 |
| 안쪽 여백선 | 켜기/끄기, 여백, 두께, 색, 실선/점선 |
| 십자·등분 기준선 | 켜기/끄기, 십자·3등분·4등분 빠른 선택, 가로·세로 등분 수 따로 입력(1~20), 두께, 색, 실선/점선 |
| 큰 크기 | 한 변 최대 16,384px까지 생성, 미리보기는 화면에 맞게 축소 |
| 저장 | 원본 크기 PNG, 몇 번이든 반복 저장. 파일 이름을 비워 두면 `template.png`, 입력하면 그 이름으로 저장 |
| 공유 | 이미지 공유(PNG를 카카오톡·메일 등으로), 설정 링크 공유·복사, 메일로 보내기 — 서버 없이 동작 |

- 설정은 브라우저에 자동 저장되어 다음에 열어도 그대로 남습니다. (헤더의 **기본값으로** 버튼으로 초기화, 파일 이름은 저장하지 않음)
- 미리보기: 드래그로 이동, 휠·핀치로 확대/축소, 더블클릭으로 화면 맞춤, `1:1`로 원본 배율 보기
- 단축키: `Ctrl`/`⌘` + `S` 로 PNG 저장, 파일 이름 칸에서 `Enter`로 저장

### 공유

저장 버튼 옆 공유 버튼(↑)을 누르면 메뉴가 열립니다.

- **이미지 공유**: 기기 공유창으로 PNG 파일을 보냅니다. 휴대폰에서는 카카오톡·메일·메시지 등을 고를 수 있습니다. (공유창을 지원하는 브라우저에서만 보임)
  큰 이미지는 만드는 데 시간이 걸려 공유창이 바로 안 열릴 수 있는데, 그때는 한 번 더 누르면 바로 열립니다.
- **설정 링크 공유 / 복사**: 지금 설정을 주소 `#` 뒤에 담은 링크를 만듭니다. 받는 사람이 링크를 열면 같은 템플릿이 바로 뜹니다.
- **메일로 보내기**: 메일 앱을 설정 링크가 담긴 상태로 엽니다. (메일 앱 특성상 파일 첨부는 안 됨)

### 그리는 기준

- 박스 크기는 테두리를 포함한 박스 영역입니다. 테두리 위치가 **안쪽**이면 박스 크기 안에 테두리가 그려지고, **바깥쪽**이면 박스 바깥(간격·여백 쪽)에 그려집니다.
- 안쪽 여백선은 박스 가장자리에서 여백만큼 들어간 지점부터 선이 시작됩니다.
- 십자·등분 기준선은 박스를 가로·세로로 n등분하는 위치에 그려지며(2등분 = 십자), 픽셀 경계에 맞춰 흐릿해지지 않습니다.
- 톰보는 박스 경계의 연장선 위에 그려지며, 간격과 바깥 여백에만 나타납니다. 간격·여백이 0이면 보이지 않습니다.
- 최종 캔버스 크기 = `바깥 여백 × 2 + 박스 크기 × 개수 + 간격 × (개수 − 1)`

### 브라우저 한도

- PC의 Chrome·Edge·Firefox·Safari는 한 변 16,384px까지 저장할 수 있습니다. (16,000×16,000 기준 저장에 수 초 소요)
- iPhone·iPad Safari는 캔버스 면적 한도(약 4096×4096)가 있어 그보다 큰 캔버스는 저장되지 않을 수 있습니다. 화면에 안내가 표시됩니다.

## 파일 구성

```
index.html   화면 구성
style.css    디자인 (라이트/다크 모드, 모바일 대응)
app.js       설정 상태, 캔버스 그리기, 미리보기, PNG 저장, 공유
```

## 로컬에서 실행

`index.html`을 브라우저로 바로 열어도 동작합니다. 로컬 서버로 확인하려면:

```bash
python -m http.server 5173
```

그다음 <http://localhost:5173> 을 엽니다.

## GitHub Pages 배포

1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올립니다.
   ```bash
   git init
   git add index.html style.css app.js README.md
   git commit -m "이모티콘 캔버스 템플릿 생성기"
   git branch -M main
   git remote add origin https://github.com/<사용자명>/<저장소명>.git
   git push -u origin main
   ```
2. 저장소의 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 선택하고 저장합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속할 수 있습니다.
